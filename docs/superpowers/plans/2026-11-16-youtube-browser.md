# YouTube 完整站点浏览与下载分发

**目标：** 在现有 Web 系统内浏览完整 YouTube 网站，从当前视频创建下载任务，并在下载成功后发布到选定的多个账号。

**已确认交互：** 用户选择“需要浏览完整 YouTube 网站”，保留视频下载、多账号选择与文案编辑流程，并要求完成后提交、推送。

**实现方式：** FastAPI 管理独立的本机 Chrome 浏览会话，将网页画面和鼠标键盘交互接入 Vue 页面。页面提供地址/搜索、前进后退、当前视频下载、下载并发布。浏览器登录资料保留在忽略的 runtime 目录；下载继续使用设置中的代理与 YouTube Cookie。画面传输不提供音频，播放可在真实浏览器窗口中继续。

**约束：** 保持现有 Web 架构，不恢复 Qt/mpv；不修改已有账号凭据或数据库结构；仅复用现有下载与发布 worker；下载失败不发布；提交幂等；发布仍使用平台正向回执，不自动重发待核实结果。真实发布不属于测试。
