拾光分发浏览器助手（Chrome / Edge）

1. 将压缩包解压到一个固定文件夹。
2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
4. 返回拾光分发的设置页面并刷新。
5. 在同一个浏览器和个人资料中登录 YouTube，然后点击“一键从当前浏览器导入”。

只读取当前浏览器个人资料中的 YouTube / Google Cookie，并在点击导入后交给本机拾光分发。
不读取浏览历史或其他网站的 Cookie，不向第三方服务器发送凭据。
导入后，关闭并重新启动拾光分发内的 YouTube 浏览会话。
